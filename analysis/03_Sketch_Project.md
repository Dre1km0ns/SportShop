# Практическая работа №3. Эскизный проект

## 1. Постановка задачи
Консольная программа учёта товаров и продаж магазина спортивных товаров.

## 2. Метод решения и язык программирования
Структурно-модульный подход; язык Python 3.10+ (кроссплатформенность, стандартные модули json, unittest).
Режимы: интерактивный (меню) и демонстрационный (`--demo`).

## 3. Спецификации процессов
| Процесс | Вход | Выход | Модуль |
|---|---|---|---|
| Загрузка каталога | products.json | список товаров | storage |
| Поиск | запрос, категория, цена | товары | catalog |
| Корзина | id, размер, количество | корзина, сообщение | cart |
| Заказ | корзина, клиент | заказ | orders |
| Аналитика | заказы | показатели | analytics |

## 4. Диаграммы
- `diagrams/dfd_context.png` — контекстная DFD;
- `diagrams/dfd_level1.png` — DFD первого уровня;
- `diagrams/er.png` — «сущность–связь»;
- `diagrams/usecase.png` — варианты использования;
- `diagrams/structure.png`, `functional.png` — структурная и функциональная схемы;
- `diagrams/flowchart.png` — алгоритм оформления заказа;
- `diagrams/constantine.png`, `jackson.png` — структурные карты.

Диаграммы описаны на языке DOT (Graphviz) и собираются командой:
```bash
cd analysis/diagrams && for f in *.dot; do dot -Tpng $f -o ${f%.dot}.png; done
```

## 5. Словарь терминов
| Термин | Определение |
|---|---|
| Каталог | список товаров с ценами и остатками по размерам |
| Остаток | количество единиц товара данного размера |
| Низкий остаток | суммарный остаток ≤ 3 шт. |
| Корзина | позиции, выбранные покупателем до оформления |
| Заказ | зафиксированная покупка: клиент, дата, позиции, сумма |
| Выручка | сумма всех заказов |
| Средний чек | выручка / число заказов |
