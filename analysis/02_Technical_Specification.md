# Практическая работа №2. Техническое задание (ГОСТ 19.201-78)

## 1. Введение
Наименование: программа «СпортТовары». Область применения: учёт товаров и продаж розничного магазина спортивных товаров.

## 2. Основания для разработки
Задание на учебную практику УП. Тема: «СпортТовары — система управления магазином».

## 3. Назначение разработки
Функциональное — ведение каталога, корзины, заказов и аналитики. Эксплуатационное — использование менеджерами и продавцами.

## 4. Требования к программе
### 4.1. Функциональные характеристики
1. Просмотр каталога (id, название, бренд, категория, цена, размеры с остатками).
2. Поиск по подстроке названия/бренда, категории, диапазону цены.
3. Вывод товаров с суммарным остатком ≤ 3.
4. Добавление в корзину с проверкой размера и остатка; изменение и удаление позиций.
5. Оформление заказа со списанием остатков; сохранение и загрузка заказов в JSON.
6. Аналитика: выручка, средний чек, самый продаваемый товар, количество по категориям, средняя цена.

Входные данные — `data/products.json`, ввод с клавиатуры. Выходные — экранные формы, `data/orders.json`.

### 4.2. Надёжность
Некорректный ввод не приводит к аварийному завершению; отсутствие файла заказов не является ошибкой.

### 4.3. Условия эксплуатации
Офисные условия; пользователь — базовые навыки работы с ПК; 1 оператор на рабочее место.

### 4.4. Состав и параметры технических средств
ПК: процессор от 1 ГГц, ОЗУ от 2 ГБ, 50 МБ свободного места.

### 4.5. Информационная и программная совместимость
Python 3.10+, кодировка UTF-8, формат данных JSON, ОС Windows/Linux/macOS.

### 4.6. Маркировка, упаковка, транспортирование, хранение
Требования не предъявляются (распространение через Git-репозиторий).

## 5. Требования к программной документации
README.md, справочник API, руководство пользователя, руководство разработчика, отчёт о тестировании.

## 6. Технико-экономические показатели
Сокращение времени поиска товара и оформления заказа; отсутствие затрат на лицензии.
