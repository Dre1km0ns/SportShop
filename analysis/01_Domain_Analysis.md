# Практическая работа №1. Анализ предметной области

## 1. Предметная область и название ИС
**Предметная область:** розничный магазин спортивных товаров (обувь, одежда, инвентарь).
**Название ИС:** «СпортТовары — система управления магазином».

Магазин закупает товары у поставщиков, хранит их на складе в разрезе размеров, продаёт покупателям,
ведёт учёт заказов, анализирует продажи, производит отчисления в налоговые органы и предоставляет отчётность.

## 2. Цель ИС
Автоматизация учёта ассортимента и остатков по размерам, оформления заказов покупателей и
формирования аналитики продаж для своевременного пополнения склада.

## 3. Анализ осуществимости
| Вопрос | Ответ |
|---|---|
| Что будет, если система не будет введена? | Учёт вручную: ошибки в остатках, распроданные ходовые размеры, потеря выручки |
| Текущие проблемы | Нет оперативных данных об остатках, долгий поиск, нет статистики продаж |
| Вклад в цели бизнеса | Наличие ходовых товаров, снижение издержек учёта, данные для закупок |
| Новые технологии? | Нет: Python, JSON/SQLite — бесплатны, без серверного ПО |

## 4. Размещение и пользователи
ИС размещается на рабочих станциях магазина (касса, рабочее место менеджера).
| Пользователь | Задачи |
|---|---|
| Менеджер магазина | каталог, остатки, аналитика, закупки |
| Продавец-кассир | корзина, оформление заказов |
| Владелец | аналитика продаж, выручка |

## 5. Комплекс технических средств
| Группа | Состав |
|---|---|
| Компьютерная техника | 2 ПК (Core i3, 8 ГБ ОЗУ, SSD 256 ГБ), монитор 22" |
| Коммуникационная техника | маршрутизатор Wi-Fi, ЛВС Ethernet, Интернет |
| Организационная техника | сканер штрихкодов, фискальный регистратор, ИБП |
| Оперативная полиграфия | лазерный принтер, принтер этикеток |

## 6. Системное ПО
Windows 10/11 или Linux, Python 3.10+, Git, антивирус, средства резервного копирования.

## 7. Функции и информационные потоки
- I-1 (из внешней среды в систему управления): накладные поставщиков, заказы покупателей;
- I-2 (из системы управления во внешнюю среду): чеки, отчётность в налоговые органы;
- I-3 (от системы управления к объекту управления): распоряжения о закупке и списании;
- I-4 (от объекта к системе управления): данные об остатках и продажах.

## 8. Риски и контрольные точки
| Риск | Мера |
|---|---|
| Ошибки ввода остатков | проверка размера и количества при добавлении в корзину |
| Потеря данных | хранение в JSON + Git, резервное копирование |
| Срыв сроков | спринты по 1 занятию, приоритизация backlog |

Контрольные точки: ТЗ (ПР №2), архитектура (ПР №3), прототип (ПР №6), тесты (ПР №8), релиз v1.0 (ПР №10).
