## Какие ошибки найдены и исправлены
1. Ключи размеров из JSON — строки (см. `13_Debugging.md`); исправлено в `load_products`.
2. `add_to_cart` позволял добавить больше товара, чем есть на складе, при повторном добавлении —
   добавлен учёт уже лежащего в корзине количества.
3. `avg_price([])` вызывал `ZeroDivisionError` — добавлена проверка пустого списка.

## Какие функции остались без тестов и почему
- `create_order`, `save_orders`, `load_orders` — работают с файлами и состоянием каталога; покрываются интеграционными тестами на следующем занятии.
- `print_order` — только вывод на экран.
- `total_revenue`, `best_selling_product`, `average_order_total` — зависят от заказов; тестируются после выделения модуля аналитики.
