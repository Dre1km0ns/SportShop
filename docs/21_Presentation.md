**Цель:** консольное приложение для учёта товаров, корзины, заказов и аналитики магазина спортивных товаров.
**Задачи:** спроектировать backlog (Scrum/Kanban); реализовать функции каталога, корзины, заказов, аналитики;

# Слайд 3. Архитектура
```
main.py (меню)
   ├── src/catalog.py   ← src/cart.py ← src/orders.py
   ├── src/analytics.py
   └── src/storage.py  ↔  data/products.json, data/orders.json
build.py → tests/ → main.py --demo
```

# Слайд 4. Основные функции
- Каталог, поиск по названию/бренду/категории/цене, низкие остатки (≤ 3).
- Корзина с проверкой размера и остатка.
- Оформление заказа, списание остатков, JSON.
- Аналитика: выручка, средний чек, лидер продаж, категории.

# Слайд 5. Демонстрация
