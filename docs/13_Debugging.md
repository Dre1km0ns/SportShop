# Отладка с точками останова (занятие №8)

## Конфигурация
VS Code → Run and Debug → конфигурация **Python File** (`launch.json` с `"program": "${file}"`).

## Где была точка останова?
`shop.py`, функция `get_low_stock`, строка `return sorted(low, key=total_quantity)`.
Вторая точка — в `add_to_cart`, строка `if size not in product['sizes']:`.

## Какие значения принимали переменные? (панель Variables)
При вызове на данных `data/products.json`:

| Переменная | Значение |
|---|---|
| `limit` | `3` |
| `low` | `[{'id': 2, 'name': 'Ultraboost Light', ... 'sizes': {'41': 1, '42': 1}}, {'id': 5, ...}, {'id': 7, ...}]` |
| `size` (в `add_to_cart`) | `40` (int) |
| `product['sizes']` | `{'40': 4, '41': 3, '42': 2}` — **ключи-строки** |

Step Into (F11) из `get_low_stock` переводит в `total_quantity`, Step Over (F10) выполняет строку целиком, Step Out (Shift+F11) возвращает в вызывающую функцию.

## Какая ошибка была найдена?
JSON не поддерживает числовые ключи, поэтому после загрузки каталога размеры становились строками (`'40'`),
а пользователь вводит число `40`. В результате `add_to_cart(cart, products, 1, 40, 2)` всегда возвращал
`(False, 'Размер 40 отсутствует')`.

**Исправление:** в `load_products` ключи размеров приводятся к числам функцией `_to_number`
(строковые размеры одежды `S/M/L` остаются строками). После исправления сценарий добавления в корзину работает.
