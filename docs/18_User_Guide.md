# Руководство пользователя — СпортТовары

Запуск: `python main.py`. Выбор пункта — ввод цифры и Enter.

```
===== СпортТовары =====
1. Каталог
2. Поиск товара
3. Товары с низким остатком
4. Добавить в корзину
5. Показать корзину
6. Изменить количество / удалить из корзины
7. Оформить заказ
8. Аналитика
9. Список заказов
0. Выход
```

## 1. Просмотр каталога
**Команда:** `1`
**Ожидаемый результат:**
```
ID  Название                   Бренд    Категория       Цена  Размеры (остаток)
1   Air Zoom Pegasus 40        Nike     Обувь       11990.00  40:4, 41:3, 42:2
2   Ultraboost Light           Adidas   Обувь       15490.00  41:1, 42:1
...
8   Коврик для йоги            Demix    Инвентарь    1790.00  183:12
```

## 2. Поиск товара
**Команды:** `2` → `nike` → Enter (любая категория)
**Ожидаемый результат:**
```
1   Air Zoom Pegasus 40        Nike     Обувь       11990.00  40:4, 41:3, 42:2
4   Футболка Dri-FIT           Nike     Одежда       2990.00  S:6, M:8, L:4
```
Если ничего не найдено — `Ничего не найдено`. Пункт `3` показывает товары с остатком ≤ 3:
```
  Ultraboost Light — осталось 2 шт.
  Шорты беговые — осталось 3 шт.
  Гантели 2x5 кг — осталось 3 шт.
```

## 3. Добавление в корзину
**Команды:** `4` → ID `1` → размер `40` → количество `2`
**Ожидаемый результат:** `Товар добавлен в корзину`
Несуществующий размер (`4` → `2` → `99` → `1`): `Размер 99 отсутствует`.
Просмотр корзины (`5`):
```
  [1] Air Zoom Pegasus 40 р.40 x2 = 23980.00
Итого: 23980.00 руб.
```
Изменение количества — пункт `6` (0 удаляет позицию).

## 4. Оформление заказа
**Команды:** `7` → `Иванов И.`
**Ожидаемый результат:**
```
Заказ №20261010125557864682 от 2026-10-10 12:55
Клиент: Иванов И.
  Air Zoom Pegasus 40 (р. 40) x2 = 23980.00 руб.
Итого: 23980.00 руб.
```
Остатки на складе уменьшаются, каталог сохраняется в `data/products.json`.

## 5. Просмотр аналитики
**Команда:** `8`
```
Товаров по категориям: {'Обувь': 3, 'Одежда': 2, 'Инвентарь': 3}
Средняя цена товара: 7102.50 руб.
Заказов: 1, выручка: 23980.00 руб., средний чек: 23980.00 руб.
Самый продаваемый товар: Air Zoom Pegasus 40
```

## 6. Сохранение и загрузка заказов
Заказы автоматически сохраняются в `data/orders.json` после оформления и загружаются при следующем запуске.
**Команда:** `9`
```
  №20261010125557864682 2026-10-10 12:55 Иванов И.: 23980.00 руб.
```
Выход — `0` (`До свидания!`).
