# Product Backlog — «СпортТовары»

Приоритеты: 4 высоких, 3 средних, 3 низких.

### US-1. Товары с низким остатком
**Как** менеджер магазина, **я хочу** видеть список товаров с суммарным остатком ≤ 3, **чтобы** вовремя заказать новую партию.

**Критерии приёмки:**
- Отображаются товары с суммарным количеством ≤ 3
- Список отсортирован по возрастанию количества
- Если таких нет — сообщение «Нет товаров с низким остатком»

**Оценка:** 3 story points  
**Приоритет:** Высокий

### US-2. Поиск товаров
**Как** менеджер, **я хочу** искать товары по названию и бренду, **чтобы** быстро находить нужную позицию.

**Критерии приёмки:**
- Поиск нечувствителен к регистру
- Ищется подстрока в названии и бренде
- Пустой результат — сообщение «Ничего не найдено»

**Оценка:** 5 story points  
**Приоритет:** Высокий

### US-3. Корзина
**Как** покупатель, **я хочу** добавлять товары нужного размера в корзину, **чтобы** оформить покупку.

**Критерии приёмки:**
- Нельзя добавить несуществующий размер
- Нельзя добавить больше остатка
- Повторное добавление увеличивает количество

**Оценка:** 5 story points  
**Приоритет:** Высокий

### US-4. Оформление заказа и сохранение в JSON
**Как** менеджер, **я хочу** оформлять заказ и сохранять его в JSON, **чтобы** не терять историю продаж.

**Критерии приёмки:**
- Заказ содержит клиента, дату, позиции, сумму
- Остатки списываются
- Заказы сохраняются в data/orders.json и загружаются обратно

**Оценка:** 8 story points  
**Приоритет:** Высокий

### US-5. Аналитика по категориям
**Как** менеджер, **я хочу** видеть количество товаров по категориям и среднюю цену, **чтобы** анализировать ассортимент.

**Критерии приёмки:**
- Выводится словарь категория → количество
- Выводится средняя цена

**Оценка:** 5 story points  
**Приоритет:** Средний

### US-6. Аналитика продаж
**Как** владелец магазина, **я хочу** видеть выручку, средний чек и самый продаваемый товар, **чтобы** оценивать работу магазина.

**Критерии приёмки:**
- Выручка = сумма всех заказов
- При отсутствии заказов выводится 0

**Оценка:** 5 story points  
**Приоритет:** Средний

### US-7. Изменение корзины
**Как** покупатель, **я хочу** менять количество и удалять позиции, **чтобы** исправлять ошибки до оформления.

**Критерии приёмки:**
- Количество 0 удаляет позицию
- Нельзя указать больше остатка

**Оценка:** 3 story points  
**Приоритет:** Средний

### US-8. Журнал действий
**Как** менеджер, **я хочу** видеть журнал действий, **чтобы** контролировать операции.

**Критерии приёмки:**
- Каждая операция записывается с датой и временем

**Оценка:** 3 story points  
**Приоритет:** Низкий

### US-9. Сохранение каталога
**Как** менеджер, **я хочу** сохранять изменения каталога в JSON, **чтобы** остатки не терялись между запусками.

**Критерии приёмки:**
- После заказа каталог сохраняется в data/products.json

**Оценка:** 2 story points  
**Приоритет:** Низкий

### US-10. Сортировка каталога
**Как** покупатель, **я хочу** сортировать каталог по цене и названию, **чтобы** удобно выбирать товар.

**Критерии приёмки:**
- Доступна сортировка по возрастанию цены
- Доступна сортировка по названию

**Оценка:** 2 story points  
**Приоритет:** Низкий
